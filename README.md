# نصب‌کننده گواهی SSL چنددامنه‌ای

اسکریپت Bash برای دریافت و نصب گواهی امنیتی SSL/TLS مشترک برای چند دامنه با استفاده از **Let's Encrypt** و **Certbot**.

این ابزار برای ساده‌سازی فرایند دریافت گواهی SSL در سرورهای لینوکسی طراحی شده و عمدتاً برای Ubuntu و توزیع‌های مبتنی بر Debian مناسب است.

## امکانات

- نصب خودکار Certbot
- دریافت یک گواهی SSL برای چند دامنه
- دریافت نام گواهی و ایمیل به‌صورت تعاملی
- بررسی اولیهٔ نام دامنه‌ها و ورودی‌های کاربر
- بررسی وضعیت پورت ۸۰
- نمایش اطلاعات گواهی صادرشده
- نمایش مسیر فایل گواهی و کلید خصوصی
- آزمایش فرایند تمدید خودکار با قابلیت `dry-run` در Certbot

## پیش‌نیازها

- سرور لینوکسی Ubuntu یا Debian
- دسترسی مدیر سیستم (`root` یا `sudo`)
- اتصال به اینترنت
- تنظیم صحیح DNS دامنه‌ها به سمت سرور
- دسترسی ورودی به پورت TCP شماره ۸۰ برای اعتبارسنجی HTTP-01
- یک آدرس ایمیل معتبر

## نصب

برای دریافت و اجرای اسکریپت در ترمینال سرور، دستور زیر را اجرا کنید:

```bash
curl -fsSL https://raw.githubusercontent.com/roshd60mhn/multi-cert-roshdcollection/main/multi-cert-roshdcollection.sh | sudo bash
```

اگر با کاربر `root` وارد سرور شده‌اید، دستور زیر کافی است:

```bash
curl -fsSL https://raw.githubusercontent.com/roshd60mhn/multi-cert-roshdcollection/main/multi-cert-roshdcollection.sh | bash
```

## نحوه استفاده

پس از اجرای اسکریپت، مراحل زیر را انجام دهید:

۱. نام گواهی را وارد کنید.

۲. آدرس ایمیل خود را وارد کنید.

۳. نام هر دامنه را در یک خط جداگانه وارد کنید.

۴. پس از واردکردن آخرین دامنه، یک خط خالی ثبت کنید.

۵. فهرست دامنه‌ها را بررسی کرده و صدور گواهی را تأیید کنید.

در پایان، یک گواهی مشترک شامل تمام دامنه‌های واردشده درخواست می‌شود.

## مسیر فایل‌های گواهی

پس از صدور موفقیت‌آمیز گواهی، فایل‌ها معمولاً در مسیرهای زیر قرار می‌گیرند:

```text
/etc/letsencrypt/live/نام-گواهی/fullchain.pem
/etc/letsencrypt/live/نام-گواهی/privkey.pem
```

- `fullchain.pem`: گواهی و زنجیرهٔ گواهی‌ها
- `privkey.pem`: کلید خصوصی گواهی

نام پوشه با نام گواهی‌ای که هنگام اجرای اسکریپت وارد کرده‌اید مطابقت دارد.

## نکات مهم

- همهٔ دامنه‌ها باید به‌درستی به سرور موردنظر اشاره کنند.
- برای اعتبارسنجی HTTP-01، پورت ۸۰ باید از اینترنت قابل دسترسی و هنگام اعتبارسنجی آزاد باشد.
- اگر پورت ۸۰ اشغال است، پیش از توقف هر سرویس، کاربرد آن را بررسی کنید.
- آزمایش تمدید خودکار به‌تنهایی پیکربندی وب‌سرور برای استفاده از گواهی را انجام نمی‌دهد.
- پس از صدور گواهی، باید وب‌سرور یا برنامهٔ خود را برای استفاده از مسیرهای گواهی تنظیم کنید.
- کلید خصوصی `privkey.pem` محرمانه است؛ آن را منتشر نکنید.
- پیش از اجرای اسکریپت با دسترسی مدیر، کد آن را بررسی کنید.
